# Contribution Rules

## Branches

- Never work directly on the `main` branch.
- Create and use a separate branch for every feature, bug fix, or other standalone change.
- Keep each branch focused on one feature or change.

## Commits

- Commit whenever a standalone change is complete.
- Use a clear commit message that describes the change.
- Keep commits focused; do not combine unrelated changes in one commit.

## Moving to the Next Feature

- When a feature is complete, open a pull request to merge its branch into `main`.
- Do not continue adding a new feature to the completed feature's branch.
- After opening the pull request, create a new branch from the appropriate up-to-date base for the next feature.
